New installation

  1. Download First-time server setup above and extract it on the computer that will be the HIVLO server.
  2. Run the setup wizard and follow the steps.
  3. Sign in, then complete the Setup Walkthrough: Check for updates, then Licence.

A licence key (starts HIVLO1-) is issued by your supplier for your server.

Update an existing HIVLO Administrators

  1. Run Administration → Backup → Run Backup Now.
  2. Download the file below that matches everything installed on your server (core, +Inventory, +Report Builder, or both).
  3. In HIVLO open Administration → Updates. Press Check now to fetch it automatically, or Browse to the file you downloaded.
  4. Press Check and use this update, tick the box and press Install. Everyone is signed out for about 5 to 10 minutes.

Check every download. Compare the SHA-256 shown with the file you received. HIVLO also verifies the digital signature of every .hivlo update and refuses anything not signed by the official supplier. If a step fails, HIVLO puts the old version back.
